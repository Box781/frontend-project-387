# Интеграционные сценарии

Проверяем, что фронтенд и бэкенд вместе проводят гостя по пути записи.

## Сценарии

1. **Гость записывается на свободный слот.** Открывает список типов, выбирает «Знакомство», день и время, вводит имя и email, видит подтверждение.
2. **Владелец видит эту встречу.** В кабинете в списке предстоящих встреч есть имя гостя.
3. **Занятый слот больше не предлагается.** После записи это время исчезает из календаря. Повторная запись на тот же `startAt` через API возвращает `409 SLOT_OCCUPIED`.

## Запуск

```bash
cd backend && npm ci
cd ../frontend && npm ci
cd ../e2e && npm ci && npx playwright install --with-deps chromium
npm test
```

Из корня репозитория: `make e2e`.
